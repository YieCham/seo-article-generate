# 提示词文档

本目录记录 **ai-article-agent** 当前程序实际调用的 LLM 提示词来源与组装方式。

| 文件 | 说明 |
|------|------|
| [提示词说明-白话版.md](./提示词说明-白话版.md) | 按进度板和状态栏的步骤名，写工作流和每一步的提示词 |
| [提示词总览.md](./提示词总览.md) | 按流水线步骤整理：角色设定、注入块、动态变量、代码位置 |

**维护说明**

- 提示词分散在 `src/main/agent/*.ts` 与 `.cursor/skills/*/SKILL.md`（打包副本在 `src/main/bundled-skills/`）。
- Skill 正文不会整篇注入；由 `skillPipeline.ts` 按步骤截断/节选。
- 结构/字数/产品植入等硬规则多在**代码常量**中，而非仅在 Skill 里。

若改了某一步的 system/user 文案，请同步更新《提示词总览.md》对应小节，并视情况改《提示词说明-白话版.md》里同一件事的说法。
